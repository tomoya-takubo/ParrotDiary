## 🎯 概要

ParrotDiaryは、「日記をつけたいのに続かない」という課題を解決するため、ガチャとコレクション要素を組み合わせた3行感情日記アプリです。書いた日記でガチャチケットを獲得し、PartyParrotをコレクションすることで、内省習慣の継続を楽しくサポートします。

## ✨ 主な機能

### 📝 **3行感情日記**
- シンプルな3行形式で気軽に記録
- 感情タグによる分類・検索機能
- PartyParrotスタンプでデコレーション

### 🎲 **ガチャ＆コレクション**
- 日記投稿でガチャチケット獲得
- レアリティ別PartyParrotコレクション
- コレクション完成度の可視化

### 📊 **継続サポート機能**
- カレンダーヒートマップで習慣可視化
- レベルシステムと経験値機能
- 継続日数ランキング（ブロンズ〜プラチナ）

### 🔐 **認証・データ管理**
- Supabase認証によるセキュアなログイン
- 日記データのCSV出力・検索機能
- Row Level Security による個人データ保護

### 📱 **ユーザー体験**
- レスポンシブデザイン（PC・スマホ対応）
- 直感的なタッチ操作とアニメーション
- アクセシビリティ配慮（WCAG 2.1 AA準拠）
  - キーボード操作・スクリーンリーダー完全対応
  - ARIA属性による適切な情報提供
  - フォーカス管理とフォーカストラップ機能

## 技術スタック

- **フレームワーク**: Next.js 15 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS + CSS Modules
- **データベース**: Supabase (PostgreSQL)
- **認証**: Supabase Auth
- **状態管理**: React Context + useState/useEffect

## 🚀 使い方

### 1. アカウント作成・ログイン
1. ランディングページから「はじめる」をクリック
2. 新規アカウント作成またはログイン
3. メール認証でアカウント有効化

### 2. 日記の記録
1. ダッシュボードから「今日の気持ちを記録」
2. 3行形式で感情や出来事を入力
3. 感情タグを選択（おすすめタグ表示）
4. PartyParrotスタンプを追加（任意）
5. 保存でガチャチケット獲得

### 3. ガチャとコレクション
1. チケットを使ってガチャを実行
2. レアリティ別PartyParrotを獲得
3. コレクションページで図鑑確認
4. 完成度とレアリティ統計を表示

### 4. 継続習慣の確認
1. カレンダーヒートマップで活動履歴確認
2. 連続記録日数とランク表示
3. レベル・経験値の進捗確認

### 5. 過去の振り返り
1. 日記検索ページで過去記録を検索
2. タグ・日付・キーワードで絞り込み
3. CSV形式でデータエクスポート

## データ管理について

このアプリケーションは、データをSupabaseのPostgreSQLデータベースに保存します。
- 13テーブル構成（正規化設計）
- Row Level Security (RLS) によるデータ保護
- リアルタイムでのデータ同期
- インデックス最適化によるクエリ高速化
- 自動バックアップとセキュリティ
